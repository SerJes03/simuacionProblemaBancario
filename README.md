# 🏦 Simulación de un Sistema Bancario

## Descripción

Este proyecto implementa una simulación de un sistema de atención bancaria utilizando técnicas de simulación de eventos discretos. El objetivo es analizar el comportamiento de los clientes dentro de una entidad bancaria, evaluando tiempos de espera, tiempos de servicio y desempeño de los cajeros.

## 🎯 Objetivo

Aplicar conceptos de simulación para:

* Modelar el proceso de atención de clientes en un banco.
* Analizar tiempos de espera en las filas.
* Evaluar el desempeño de los cajeros.
* Obtener métricas de eficiencia del sistema.
* Identificar posibles cuellos de botella en la atención.

## 🛠 Tecnologías utilizadas

* Python
* SimPy
* Pandas
* NumPy
* Matplotlib

## ▶️ Cómo ejecutar el proyecto

### Opción 1: Google Colab

1. Abrir el archivo del proyecto en Google Colab.
2. Ejecutar todas las celdas en orden.
3. Visualizar los resultados generados por la simulación.

### Opción 2: Ejecución local

1. Instalar Python 3.x.
2. Instalar las dependencias necesarias:

```bash
pip install simpy pandas numpy matplotlib
```

3. Ejecutar el archivo principal:

```bash
python simulacion_banco.py
```

## 📊 Resultados obtenidos

La simulación permite analizar:

* Tiempo promedio de espera de los clientes.
* Tiempo promedio de servicio por cajero.
* Número de clientes atendidos.
* Utilización de los recursos del sistema.
* Comparación del desempeño entre cajeros.
